# evalAI — пример оценки качества LLM-агента

Проект демонстрирует работу с Eval AI Library: как проверять ответы LLM-агента с помощью тестовых кейсов и метрик, находить ошибки и сравнивать результаты после изменения промпта.

В качестве примера используется агент-консультант по элитной недвижимости. Это демонстрационный сценарий, а не готовый продукт.

## Зачем это нужно

После изменения промпта ответы могут казаться лучше, но субъективного впечатления недостаточно. Оценка по метрикам помогает понять:

- отвечает ли агент на вопрос пользователя;
- соблюдает ли свою роль и границы компетенции;
- соответствует ли ответ ожидаемому поведению;
- действительно ли изменения промпта улучшили результат.

## Что показано в проекте

На шести тестовых кейсах демонстрируется цикл:
получить ответы → оценить метриками → разобрать ошибки → изменить промпт → повторить оценку.
