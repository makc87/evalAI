# Как устроены проверки evalAI

| Файл | Назначение |
| --- | --- |
| `golden_cases.json` | Сценарии: `id` — идентификатор, `input` — запрос, `expected_behavior` — описание ожидаемого поведения, не точный текст ответа. |
| `case_loader.py` | Читает JSON и проверяет, что это непустой список объектов с обязательными непустыми строковыми полями. При поиске дубликатов игнорирует пробелы по краям ID; исходные значения не переписывает. |
| `tests/test_case_loader.py` | Проверяет реальный набор и подставляет некорректные данные через временные файлы. |
| `prompt.txt` | Системные инструкции агенту. |
| `main.py` | Демонстрация оценки заранее записанного ответа. |
| `main_dotpoin_eval.py` | Получает ответы модели через API и передаёт их метрикам. Пока читает JSON самостоятельно, без нового загрузчика. |

В JSON не добавляем комментарии: пояснения к данным храним здесь.

## Запуск в PyCharm

Выбери интерпретатор проекта с установленным `pytest`. В дереве проекта нажми правой кнопкой на `tests/test_case_loader.py` и запусти тесты через pytest. Или в терминале PyCharm из корня проекта выполни `python -m pytest -q`.

Эти тесты проверяют данные и загрузчик, а не качество ответов агента. API-ключ и сеть для их запуска не нужны.
